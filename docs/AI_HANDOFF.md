# AI 与作者协作入口

这是普通作者文档与可复制提示词，不是训练获得的能力，不依赖 skill，也不安装到全局技能目录。README、支持矩阵、准备契约是权威入口。

## 开工规则

先判断实际输入格式与所处阶段；读配置、intake/audit/validation、worker.log 后再修改。只写候选或明确授权的目标；原工程、已验收模组、备份、存档、播放集分别保护。非 Unity 来源不用强行进入 Unity；UnityPackage 清单不能充当最终 Avatar。

先检查实际部件、骨架、贴图、shader/effect 和相机，再做局部改动。不要自动删非标准骨骼、盲裁身体、猜镜头字段、把 toon 参数当 CK3 PBR，或为消警告自行关闭颈骨保护。stance 默认关闭；未验证的宽站姿和混合问题须保留。

构建、安装、游戏加载和视觉验收分别留证。用户执行游戏测试；未明确授权不要启动游戏、接管手工 Mod、改播放集或发布角色。公开只用白名单；模型许可、CK3 原始/派生文件和第三方依赖分别处理。

## 可复制制作请求

> 使用本目录的 CK3 Character Toolkit 和作者指南，将我指定且有权使用的人物模型制作成独立 CK3 候选。先按 SUPPORTED_TYPES 判断可导入阶段；若是 VRC，确认最终装配及穿搭。保留源工程、现有模组和备份。说明缺失的 prepared-reference-v1 输入，不冒称原始 Avatar 一键转换。检查实际部件、材质、骨架、相机、动作和道具。按我指定的资源目录安装并读回核验后，给出实际入口/物理路径、启用步骤及未解决项。游戏内测试由我完成。

作者补充：源文件与许可、目标穿搭、参考输入、资源目录、允许修改/安装范围、预期材质与动作。

## 交接记录

记录源哈希与版本、使用的配置、准备契约、输出目录、失败/警告、修了哪些动作/跳过哪些动作、是否已安装与事务、verify-install 结果、游戏是否重启加载、用户未测项目。每个结论注明证据类型：解析、静态、离线预览、安装读回、游戏日志或用户观察。不要把某模型的结果外推为全部 VRC/VRM 或全部年龄/动作兼容。
