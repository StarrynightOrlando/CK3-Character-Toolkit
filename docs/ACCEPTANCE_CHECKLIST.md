# 人物制作与游戏验收检查表

全部项目从“未测”开始。通过项写明版本、动作/帧、观察或截图/日志位置；AI 不得把静态通过自动填成游戏通过。工具每次构建/检查另生成可填写的 TXT / HTML / JSON。

## 来源与几何

- [ ] 记录来源、许可、哈希、目标穿搭、准备契约；原工程和现有已验收 Mod 保留。
- [ ] Unity/VRC 实际启用部件与 Blender 候选一致，身体遮罩和 Shape Key 值已核对。
- [ ] 逐部件尺寸、左右、负缩放、法线、UV、材质槽与蒙皮正确。
- [ ] 身体裁切有遮罩依据，侧背面/抬腿/弯腰/坐下没有孔洞。
- [ ] 裙摆局部权重和自定义骨骼已检查；未凭名称删除物理链或辅助骨。

## 材质与相机

- [ ] .asset shader_file/effect、meshsettings.shader 和 .mesh material.shader 一致。
- [ ] 对每个材质记录 matte/cutout/face/face_cutout，确认实际像素入口是 PS_attachment。
- [ ] 基础色、alpha、法线打包、发丝正反面、边缘、选择轮廓与阴影分别看过。
- [ ] 原版 Effect 未重新导出；Runtime 只定义 12 个唯一的 ck3char_* Effect。
- [ ] 头部代理/身体骨架/相机灯光节点与挂点分别解析，不重复抢占道具节点。
- [ ] 男、女分别测试 5/12/17/18/40/70 岁，覆盖人物头像、半身面板、理发器、宮廷。
- [ ] 原版→自定义→原版、自定义→原版两种顺序通过，原版男女及儿童回归通过。

## 动作与道具

- [ ] 每段实际引用 .anim 的数量、名称、顺序、父关系、初始值、采样与有限数值合格。
- [ ] trace-state 对照实际状态及全部随机变体，未凭截图猜 body_idle_1。
- [ ] 待机、抱臂、文职、武器、祈祷、坐姿、跪拜、骑乘分别记录通过/失败/未测。
- [ ] 首中末帧、全周期及状态转换检查滑步、腿部异常、鞋袜/裙摆/长发穿插。
- [ ] 剑、双手武器、权杖、书、杯、弓、马的实际出现和握持正确。
- [ ] 坐姿与站坐切换检查御座座面、扶手、膝、袖口、长发与裙摆。
- [ ] 颈部长度保护与 stance 的改动/跳过列表已读；部分收窄未写成所有动作已适配。
- [ ] 表情、闭眼、口型、物理与衣物碰撞的未实现内容明确保留，不冒称已转换。

## 安装与交付

- [ ] 自动报告通过且所有警告有说明；已读 bundle.json 中 idle_fallbacks。
- [ ] 已安装才写“已安装”，verify-install 从注册入口读回哈希通过，物理路径明确。
- [ ] 用户核对播放集，完整退出重启，读取本次日志时间及加载错误。
- [ ] 真正游戏中的材质、镜头、动作及原版回归由用户记录。
- [ ] 多 Mod 共存单独测试，不以无重名/静态检查代替兼容验收。
- [ ] 发布白名单与来源许可检查通过；本机生成 Runtime 的分享边界单独核对。

交接结果分别填写：本地整理、源导入、准备/audit、build/compile、安装读回、游戏加载、用户视觉验收、Git 提交、远端上传。没有证据的阶段写“未完成/未验证”。
