CK3 Character Runtime / 玩家安装说明

公共 Runtime 只提供人物材质前置，不会凭空增加角色。角色来自作者提供且具备分发许可的模型组合包。
本公开仓库只提供源码和本机生成方法，没有可直接启用的完整 Runtime 附件。普通玩家应使用作者提供并注明适用版本的合法安装包。

若作者提供 Runtime ZIP，将其中 ck3char_runtime 文件夹和 ck3char_runtime.mod 放入 CK3 用户 mod 目录。启用 Runtime 和配套组合，前置在组合之前；已内置前置的独立包按其说明避免重复启用。
需要多个人物时，由作者统一 compile 选择器，不同时启用各自覆盖 animations.txt 的多个组合。

工具安装资源在 storage_root，用户 mod 目录保存入口和 .mod。阅读“测试模组位置.txt”区分入口与物理目标。不要删除仍被入口指向的版本。工具不会选择播放集或启动游戏。
完整退出到桌面并重启；仅回主菜单不会重新加载动画。Folder not found 先检查 .mod path、兼容入口与实际目标。verify-install 通过只说明磁盘一致，不说明运行中的游戏已加载。

宽站姿、衣物穿插和部分动作仍有未解决项。向作者提供截图、动作/事件名称、游戏版本和重启情况；不要将离线测试当成游戏验收。
